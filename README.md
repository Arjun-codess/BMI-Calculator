# BMI-Calculator
<br>
Learning accesing element changing innerHTML and other component of javascript.


**Description**
The BMI Calculator is a web-based application (or GUI app) designed to help users determine their Body Mass Index, indicating if they are within a healthy weight range. The calculator takes height and weight as inputs and classifies the result into categories: Underweight, Normal, Overweight, or Obese. 

**Features**
Real-time Calculation: Calculates BMI instantly upon input.
Units Support: Options for Metric (kg/cm) systems.
Health Classifications: Displays whether the user is underweight, normal, or overweight based on standard metrics.
User-Friendly Interface: Clean layout designed for ease of use. 

**Usage**
Input: Enter your weight (kg).
Input: Enter your height (cm).

Calculate: Click the "Calculate BMI" button.
Result: View your BMI score and weight status category. 

**Technology Stack**
Frontend: HTML5, CSS3, JavaScript.

**Installation** (For Web Version)
Clone this repository.
Open index.html in your web browser.
